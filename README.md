# MNK Esquadrias e Engenharia

Landing page estática em HTML, CSS e JavaScript. Inclui favicon, galeria, formulário via WhatsApp e configurações Netlify.

## Testar localmente
Abra `index.html` no navegador.

## Publicar pelo GitHub + Netlify
1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (`index.html`, `netlify.toml`, `assets/`, etc.).
3. No Netlify, escolha **Add new project > Import an existing project > GitHub** e autorize o acesso.
4. Selecione o repositório. Configurações: **Base directory** vazia, **Build command** vazio, **Publish directory** `.`.
5. Clique em **Deploy**. Novos commits na branch de produção disparam novas publicações.

Não é necessário Node.js nem variáveis de ambiente.
